Platform & SDK engineering

Real-time pose detection SDK

ApataTech · client: Blatchford Solutions, UK · 2025–present

A computer-vision SDK for a prosthetics and orthotics manufacturer: clinicians record a patient moving, and the app overlays a live skeletal model, measures joint angles, and stores video with faces redacted.

  • Unified .NET MAUI Android SDK abstracting two ML backends — MediaPipe and ML Kit — behind one public API, switchable by configuration with no consumer code changes.
  • C# binding libraries wrapping native Android AARs for both engines, including dependency-conflict resolution across parallel NuGet and Gradle chains.
  • Dual-track recorder writing raw camera and composited overlay video simultaneously via MediaCodec and MediaMuxer, with a HandlerThread encoder queue that keeps the UI thread free.
  • Live face blur on preview using a dedicated SurfaceView with pre-allocated bitmap pooling, plus post-recording redaction through Media3 Transformer on the raw stream.
  • Builder-pattern configuration API spanning 40+ feature flags, propagated through the MAUI bindable-property layer down to the native views.

Cross-platform SDK suite

Caluu Ltd · London, UK · 2025–2026

SDKs consumed by partner engineering teams, each shipped so the same capability behaves identically no matter which mobile stack a partner had already committed to.

  • Address-verification SDK delivered three ways from one specification — native iOS in Swift and MapKit, a React Native TurboModule, and a Flutter plugin.
  • Core SDK capabilities including foreground services, server-driven UI rendering and dynamic form submission, all theme-aware and configurable by the integrator.
  • KYC and identity verification covering document capture and liveness checks.
  • Payments abstraction placing Stripe, PayPal and Paystack behind a single interface.
  • Demo apps, versioned releases and integration documentation, plus hands-on onboarding for teams adopting the SDKs.
